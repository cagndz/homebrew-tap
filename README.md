# Homebrew tap

Apps by [Carlos Agúndez](https://github.com/cagndz), installable with [Homebrew](https://brew.sh).

## Menubar Player

A YouTube audio player that lives in the macOS menu bar. Apple Silicon only.

```sh
brew install --cask cagndz/tap/menubar-player
```

Source: [cagndz/menubar-player](https://github.com/cagndz/menubar-player)
